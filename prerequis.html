Partie 1

Prise en main de l'environnement

Le serveur web que vous allez installer tourne sur une machine Ubuntu distante, prêtée par Killercoda : un environnement « bac à sable » auquel on accède depuis le navigateur.

L'environnement est éphémère. Ne fermez pas votre onglet ! Quand la session Killercoda se termine, la machine est effacée avec tout ce que vous y avez installé et configuré. Faites vos captures d'écran au fur et à mesure.

1.1 Le bac à sable Ubuntu (Killercoda)

Mise en route
1

Ouvrir le bac à sable Ubuntu

▶
  1. Aller sur le playground Ubuntu de Killercoda : Killercoda Ubuntu
  2. Se connecter si le site le demande (compte gratuit).
  3. Patienter pendant le démarrage de la machine : un terminal noir s'affiche, prêt à recevoir des commandes.
2

Repérer l'interface

▶
  • Le terminal : il est connecté à une vraie machine Linux (Ubuntu), située dans un centre de données et non sur votre ordinateur.
  • Le menu en haut à droite (icône ☰) : la rubrique Traffic / Ports ouvre un onglet vers un port de la machine. Elle servira à voir votre site (partie 3).

Dans Killercoda, vous êtes connecté en root, l'administrateur de la machine : l'invite se termine par # (au lieu de $ pour un utilisateur ordinaire). Root a tous les droits : prudence avec rm !

3

Premières commandes dans Killercoda

▶

Entraînez-vous d'abord dans le terminal simulé ci-dessous (partie 1.2), puis tapez les deux commandes dans le terminal de Killercoda et cochez cette étape.

1.2 Vérifier l'environnement

Fais d'abord chaque action dans le terminal d'entraînement : elle se coche toute seule. Refais-la ensuite dans Killercoda.

  1. Vérifiez votre identité avec la commande whoami. Vous devez être root.
  2. Vérifiez la version du système.
Indice : commande pour vérifier l'OS

Utilisez la commande cat pour lire le fichier d'information système : 

cat /etc/os-release

Un seul serveur pour tout le TP : le terminal d'entraînement de chaque page est relié à la même machine simulée. Ce que vous installez ici sera encore là sur les pages suivantes, comme dans Killercoda tant que l'onglet reste ouvert.

1.3 Votre ordinateur

Plus loin dans le TP, vous observerez les échanges entre le navigateur et le serveur avec les outils de développement du navigateur, puis vous ferez des captures d'écran. Les raccourcis dépendent de votre système :

  • Ouvrir les outils de développement : F12 (ou Ctrl + Maj + I), puis l'onglet Réseau (Network).
  • Capture d'écran d'une zone : Windows + Maj + S.
  • Ouvrir les outils de développement : ⌘ + ⌥ + I, puis l'onglet Réseau (Network). Dans Safari, activer d'abord Réglages > Avancées > Afficher les fonctionnalités pour les développeurs web.
  • Capture d'écran d'une zone : ⌘ + Maj + 4.

Ton choix est mémorisé : les pages Sécurisation et Livrable afficheront les raccourcis de ton système.
