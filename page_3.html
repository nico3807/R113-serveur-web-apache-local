3. 🌐 Accéder à votre site Web (Exposition)

Killercoda permet d'ouvrir un "tunnel" pour voir le site distant.

  1. Cherchez le menu "Traffic / Ports" en haut à droite.
  2. Entrez le numéro de port : 80.
  3. Q3. Regardez l'URL générée. Expliquez pourquoi ce n'est pas "localhost".

Le port 80 est le standard pour le Web non sécurisé. L'URL est complexe car elle passe par un proxy Killercoda pour atteindre votre machine cloud.
