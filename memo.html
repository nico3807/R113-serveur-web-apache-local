Aide-mémoire : administrer un serveur Apache

Les commandes, les fichiers et les codes de statut utilisés dans ce TP, sur une machine Ubuntu (Killercoda). Les commandes d'installation et de configuration se tapent en root. La fiche memento est aussi disponible sur Moodle : Fiche memento (PDF).

Système, paquets et service

Savoir qui l'on est, installer un logiciel et piloter le service web.

CommandeSignificationRôle / utilisationArguments / options clés
whoamiWho am IAffiche le nom de l'utilisateur connecté (root dans Killercoda).Aucun
cat /etc/os-releaseConcatenateAffiche le contenu d'un fichier : ici, la version du système.Un ou plusieurs fichiers
apt updateAdvanced Package ToolMet à jour l'index des paquets disponibles. À lancer avant toute installation.Réservé à root
apt install apache2Advanced Package ToolInstalle un paquet et ses dépendances (ici le serveur web Apache, démarré aussitôt).-y répond « oui » à la question de confirmation
systemctl status apache2System ControlAffiche l'état du service : active (running), inactive (dead) ou failed.start · stop · restart · reload (relit la configuration sans couper le service)
systemctl reload apache2System ControlFait relire sa configuration à Apache, après chaque modification d'un fichier .conf.restart arrête puis redémarre

Travailler avec un compte ordinaire et donner les bons droits au bon compte.

CommandeSignificationRôle / utilisationExemples
adduserAdd userCrée un compte avec son dossier personnel (/home/nom, droits 750) et son mot de passe.adduser etudiant
su -Substitute UserOuvre une session sous un autre compte. exit revient au compte précédent.su - etudiant
ls -l / ls -ldList (long)Affiche les droits, le propriétaire et le groupe des fichiers (ou du dossier lui-même avec -d).ls -ld /var/www/html
chownChange OwnerChange le propriétaire (et le groupe) d'un fichier ou d'un dossier. Réservé à root.chown etudiant:etudiant /var/www/html/
-R : aussi tout le contenu

chmod 755 dossier

Configuration d'Apache

CommandeRôle / utilisationExemples
nanoÉditeur de texte du terminal : Ctrl+O puis Entrée enregistre, Ctrl+X quitte.nano /etc/apache2/apache2.conf
a2enconf / a2disconfActive (ou désactive) un fichier de conf-available en créant (ou supprimant) un lien dans conf-enabled.a2enconf mon_alias
a2ensite / a2dissiteMême principe pour les sites (sites-available → sites-enabled).a2ensite 000-default
apache2ctl configtestVérifie la syntaxe de toute la configuration : Syntax OK, ou le fichier et la ligne fautifs.apache2ctl configtest
htpasswdCrée ou complète un fichier de mots de passe pour l'authentification Basic. -c crée le fichier : seulement la première fois !htpasswd -c /etc/apache2/.htpasswd admin
tail -fAffiche la fin d'un fichier et la suite au fil de l'eau. Ctrl+C arrête.tail -f /var/log/apache2/access.log
curlEnvoie une requête HTTP depuis le terminal. -I : seulement les en-têtes de la réponse.curl -I localhost

Fichiers et dossiers importants

CheminRôle
/var/www/html/Racine du site (DocumentRoot) : index.html y est la page d'accueil.
/etc/apache2/apache2.confConfiguration principale : blocs <Directory>, AllowOverride (autorise ou non les .htaccess).
/etc/apache2/conf-available/
/etc/apache2/conf-enabled/		Morceaux de configuration disponibles, et ceux qui sont activés (liens créés par a2enconf). Exemple : mon_alias.conf.
/etc/apache2/sites-available/000-default.confLe site par défaut : <VirtualHost *:80>, DocumentRoot, ErrorDocument.
/var/log/apache2/access.logJournal des accès : une ligne par requête (IP, date, requête, code, taille, User-Agent).
/var/log/apache2/error.logJournal des erreurs : la cause des 403 et des 500.
/etc/apache2/.htpasswdComptes de l'authentification Basic (login et empreinte du mot de passe), hors du dossier web.
.htaccessConfiguration propre à un dossier du site, relue à chaque requête si AllowOverride l'autorise.

Codes de statut HTTP

CodeSignificationDans ce TP
200OKLa page est envoyée.
301Moved PermanentlyAdresse d'un dossier demandée sans « / » final : le navigateur est redirigé.
401UnauthorizedLe dossier /admin exige un identifiant et un mot de passe.
403ForbiddenAccès interdit : droits du disque (www-data) ou règle Require.
404Not FoundAucun fichier ne correspond à l'adresse (page oups.html avec ErrorDocument).
500Internal Server ErrorErreur côté serveur, par exemple une faute dans un .htaccess.

À retenir

Apache ne relit ses fichiers .conf qu'au démarrage ou au rechargement : après chaque modification, apache2ctl configtest puis systemctl reload apache2. Dans un navigateur, n'utilisez jamais Ctrl+W dans nano (recherche) : ce raccourci ferme l'onglet et votre session Killercoda.
