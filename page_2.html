2. ⚙️ Installation du service Web

Avant d'installer Apache, il faut mettre à jour l'index des paquets.

  1. Q1. Quelle commande avez-vous utilisée pour la mise à jour ?
  2. Installez le paquet apache2.
  3. Vérifiez que le service est lancé.

Pour mettre à jour : apt update. Pour installer : apt install apache2. Pour le statut : 

systemctl status apache2
