2. Installation du service Web

Avant d'installer Apache, il faut mettre à jour l'index des paquets.

  1. Mettez à jour l'index des paquets.
  2. Installez le paquet apache2.
  3. Vérifiez que le service est lancé.
Indice : commandes APT et systemd

Pour mettre à jour : apt update. Pour installer : apt install apache2 (répondre Y ou Entrée à la question). Pour le statut : 

systemctl status apache2

3. Accéder à votre site Web (exposition)

Killercoda permet d'ouvrir un « tunnel » pour voir le site distant.

  1. Cherchez le menu « Traffic / Ports » en haut à droite et entrez le numéro de port : 80.
  2. Affichez la page d'accueil d'Apache (« It works! »).
  3. Depuis le terminal du serveur, interrogez aussi votre site : curl localhost.
Indice : le port HTTP par défaut

Le port 80 est le standard pour le Web non sécurisé. L'URL est complexe car elle passe par un proxy Killercoda pour atteindre votre machine cloud.

Mini-jeu : quel port pour quel service ?

Sur une machine, chaque service réseau « écoute » sur un numéro de port. Associe chaque service à son port standard.

HTTP (site web non sécurisé)
HTTPS (site web sécurisé)
SSH (terminal à distance)
FTP (transfert de fichiers)
DNS (nom de domaine → adresse IP)
