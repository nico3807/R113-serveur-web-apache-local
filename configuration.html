4. Modification de contenu et droits

On simule une situation réelle en créant un utilisateur standard etudiant.

  1. Créez l'utilisateur : adduser etudiant (choisissez un mot de passe ; les autres informations peuvent rester vides : Entrée).
  2. Connectez-vous : su - etudiant
  3. Tentez de modifier /var/www/html/ (y créer un fichier, ou modifier index.html).

Q5. Quelle est la commande exacte utilisée pour rendre l'étudiant propriétaire du dossier Web ? 

chown etudiant:etudiant /var/www/html/

Créez ensuite votre index.html avec l'éditeur nano.

Indice : « Permission denied » en enregistrant index.html ?

chown sans -R ne change que le dossier : le fichier index.html installé par Apache appartient toujours à root. En tant qu'etudiant, supprimez-le (rm /var/www/html/index.html, puis y) avant de le recréer avec nano. Vérifiez les propriétaires avec ls -l /var/www/html.

Rappel : nano en bref

nano /var/www/html/index.html ouvre le fichier. Ctrl + O puis Entrée enregistre ; Ctrl + X quitte. Attention : dans un navigateur, Ctrl + W ferme l'onglet (et votre session Killercoda !).

5. Création d'un Alias

L'objectif est de faire pointer .../test vers un dossier personnel ~/dossier_test.

  1. En tant qu'etudiant, créez le dossier ~/dossier_test et une page index.html à l'intérieur.
  2. En root, créez le fichier /etc/apache2/conf-available/mon_alias.conf.
  3. Activez-le avec a2enconf mon_alias
  4. et rechargez Apache.
  5. Ouvrez .../test dans le navigateur.
Indice : configuration de l'Alias

Dans votre fichier conf :

Alias /test /home/etudiant/dossier_test
<Directory /home/etudiant/dossier_test>
    Require all granted
</Directory>

Si vous avez une erreur 403, utilisez chmod o+x /home/etudiant.

6. Logs et diagnostic

Surveillez les accès à votre serveur en temps réel.

  1. Utilisez tail -f sur le journal d'accès d'Apache (en root).
  2. Générez du trafic dans votre navigateur pendant que tail -f tourne.
  3. Générez une erreur 404 (une adresse qui n'existe pas).
Indice : emplacement des logs 
tail -f /var/log/apache2/access.log

Notez la présence de l'User-Agent (type de navigateur) sur la ligne. Ctrl + C arrête le suivi.
